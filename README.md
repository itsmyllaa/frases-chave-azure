# Extração de Frases-Chave com IA do Azure

## 📌 Descrição
Projeto usando o serviço de Linguagem de IA do Azure para extrair frases-chave de textos.

## 🗂️ Entrada
Arquivo: `inputs/texto.txt`

## ✅ Resultado
Frases-chave extraídas:
- inteligência artificial
- Azure
- análise de texto
- processamento de linguagem natural

## 💡 Aprendizados
- IA do Azure facilita a análise de textos complexos.
- Ferramenta útil para resumos, categorização e busca inteligente.
